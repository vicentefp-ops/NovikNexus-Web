The problem

Charting is the least valuable minute of a periodontal appointment, and the one that takes the longest.

The exam takes six minutes. Writing it down takes fifteen.

So it gets shortened. Four sites instead of six. Bleeding noted "where relevant". Recession skipped on the recall. The chart stops being a measurement and starts being an impression — and an impression cannot be compared to the one from last year, which is the entire point of charting in the first place.

PerioVox removes the cost of writing it down, so the complete exam becomes the easy one to do.

How it works

Three steps, in the order they happen chairside.

01

Probe and call it out

Work exactly as you do now. Tooth number, then the sites, then anything else worth noting. No wake word, no command syntax to memorise.

"One-six — five, four, six. Bleeding on all three. Furcation two, buccal."

02

It becomes structured data

Every value lands in the right cell in real time — pocket depth, recession, bleeding, suppuration, mobility, furcation. You watch the chart fill as you speak, so mistakes are caught on the spot.

Attachment loss and staging calculated as you go.

03

Sign off and send

Review the completed chart, correct anything by voice or by click, and export a patient-ready report or push the record into the software you already use.

PDF for the patient, structured export for the practice.

What it does

Built around the exam, not bolted onto a generic dictation engine.

Clinical vocabulary, not keywords

Understands pocket depth, recession, bleeding, suppuration, mobility, furcation and missing teeth — in the shorthand clinicians actually use, including numbers run together.

Staging and grading as you speak

Attachment loss, bone loss percentage and the resulting stage and grade are computed live, so the diagnosis is on screen the moment the last site is called.

Corrections without breaking rhythm

Say it again and the last value is replaced. Jump back to any tooth by number. Nothing needs to be undone in a menu.

Reports the patient understands

One click turns the chart into a visual report — where the disease is, how it has changed since the last exam, and what the plan is.

Comparison over time

Because the complete exam stops being expensive, every recall is comparable to the last. Sites that deteriorate are surfaced automatically.

Private by design

Patient data is processed for the exam and nothing else. GDPR-aligned handling, with the record staying under the practice's control.

Questions

The ones we get asked before every demo.

Does it work with a mask on, in a noisy surgery?
Yes. It is tuned for chairside conditions — masked speech, suction running, background conversation — using a headset or the device microphone. Accuracy is reported per session so you can see how it is performing in your own surgery.
Do I have to learn a command syntax?
No. You dictate the exam the way you already call it out to an assistant. Tooth, then sites, then findings. If you say something it cannot place, it asks rather than guessing.
What happens if it mishears a number?
You see every value land on screen as you speak, so it is caught immediately. Repeating the value replaces it, and any cell can be corrected by click afterwards.
Where is patient data stored?
Audio is used to produce the chart and is not retained for anything else. Records remain the practice's, exportable at any time, with GDPR-aligned processing.
Can hygienists and dentists share one account?
Each clinician gets their own profile, so charts are attributed correctly and the system adapts to how each person dictates. Practice plans cover the whole team.
